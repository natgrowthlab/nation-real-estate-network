# Habita Inmobiliaria para iOS

Cliente nativo en SwiftUI, orientado a iOS 17 o posterior. Conserva la paleta y jerarquía de Habita, con objetivos táctiles y etiquetas de accesibilidad.

1. Instala [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.
2. Desde esta carpeta ejecuta `xcodegen generate`.
3. Abre `HabitaInmobiliaria.xcodeproj` en Xcode y selecciona un simulador iPhone.

La capa visual ya está creada. La siguiente integración conectará inicio de sesión, inventario y operaciones a las APIs publicadas de la plataforma.
