# Reglas de negocio fundamentales

1. La propiedad, el lead y la relación con el propietario pertenecen a la plataforma.
2. La atribución del lead se conserva como historial append-only; una reasignación no elimina el origen.
3. Las comisiones usan reglas y snapshots almacenados con valores decimales, no cálculos de punto flotante.
4. Las entidades críticas se archivan; no se eliminan físicamente.
5. Toda transición que afecte atribución, comisión, disclosure o estado de negocio se audita.
