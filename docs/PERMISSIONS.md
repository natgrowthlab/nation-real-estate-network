# Principios de permisos

- Super Admin: configuración crítica, auditoría y seguridad de fundadores.
- Operaciones: propietarios, inmuebles, documentación, visitas y ofertas.
- Comercial: vendedores, asignaciones y rendimiento comercial.
- Asesor: su cartera de clientes, inventario permitido, visitas, ofertas y sus comisiones.

El contacto de propietarios, documentación privada, notas internas y reglas históricas de comisión no se devuelven a un asesor sin una concesión explícita. Cada revelación sensible deberá producir un evento de auditoría inmutable.
